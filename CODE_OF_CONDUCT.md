# Code de conduite

Le projet vise un environnement de recherche respectueux, collaboratif et rigoureux.

Les participants doivent :

- respecter les personnes et les familles étudiées;
- accepter les corrections fondées sur de meilleures preuves;
- critiquer les sources et raisonnements, non les personnes;
- protéger la confidentialité des personnes vivantes;
- éviter le harcèlement, les attaques personnelles et les propos discriminatoires.

Les désaccords généalogiques doivent être résolus par les sources, la méthode et une discussion
documentée.
