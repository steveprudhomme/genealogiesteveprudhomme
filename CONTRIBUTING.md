# Contribuer au projet généalogique

Les contributions doivent améliorer la qualité documentaire plutôt que simplement augmenter
le nombre de personnes dans l'arbre.

## Avant une modification

1. Vérifier que l'individu ou le fait n'existe pas déjà.
2. Rechercher la source originale ou la meilleure reproduction disponible.
3. Distinguer transcription, interprétation et hypothèse.
4. Documenter les contradictions.
5. Protéger les personnes vivantes.

## Contributions souhaitées

- nouvelles sources primaires;
- transcriptions vérifiées;
- corrections de citations;
- résolutions documentées de contradictions;
- recherches négatives utiles;
- amélioration des tâches et de la documentation.

## Git

Branches suggérées :

- `research/alfred-clarke-1921`
- `sources/marriage-1923`
- `docs/gedcom-conventions`
- `fix/citation-reference`

Les messages de commit devraient expliquer le changement généalogique, par exemple :

```text
research(alfred-clarke): document 1921 census candidates
```

ou :

```text
sources(alfred-clarke): add 1923 marriage register citation
```

## Interdictions méthodologiques

Ne pas :

- fusionner des homonymes sur le seul nom;
- attribuer des parents sur la seule base d'un arbre public;
- remplacer une estimation par une date exacte non sourcée;
- supprimer silencieusement une contradiction;
- présenter une tradition familiale comme un fait établi.
