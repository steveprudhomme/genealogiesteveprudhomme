# Evidence / Preuves

Chaque sous-répertoire de `evidence/` représente une preuve documentaire consultée durant les recherches.

Convention de nommage :

- PDF principal : `<nom_du_repertoire>.pdf`
- URL de provenance : `<nom_du_repertoire>_URL.txt`
- PNG page par page : `<nom_du_repertoire>_p001.png`, `<nom_du_repertoire>_p002.png`, etc.

Les PNG sont des rendus pixel par pixel des PDF.

- Si le PDF est un document original fourni par la source (PDF natif), les PNG reproduisent la mise en page originale de ce PDF.
- Si la source originale était une page HTML, le PDF a été constitué à partir du contenu réellement récupéré par le navigateur Web, puis les PNG ont été rendus à partir de ce PDF.
